📋 Export Format Information

Excel (.xlsx)
Best for business reports, data analysis, and sharing with stakeholders. Compatible with Excel, Google Sheets, and other spreadsheet applications.
PDF (.pdf)
Best for official reports, printing, and archiving. Professional document format with table layout.
CSV (.csv)
Best for data analysis, database imports, and simple spreadsheets. Universal compatibility.
JSON (.json)
Best for API integrations, data processing, and developer use. Includes metadata and structured data.
XML (.xml)
Best for enterprise systems, legacy integrations, and data exchange. Industry standard format.
HTML (.html)
Best for web reports, email sharing, and online viewing. Beautiful styling with statistics.
Text (.txt)
Best for simple reports, logging, and basic documentation. Universal text format.
